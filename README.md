# 데이터픽

Google 스프레드시트에서 분석한 결과를 표·차트 캡처·서술형 설명으로 기록하는 수행평가 앱입니다.

## 실행

```sh
npm install
npm run dev
```

검증: `npm run lint`, `npm run build`.

## 수업 흐름

1. **01 이상 데이터**: 열 이름·값·판단 이유를 표에 작성합니다.
2. **02 결측 데이터**: 제공된 데이터에서 결측 데이터가 있는 행을 제거하고, 제목 행을 포함한 나머지 전체 데이터를 복사해 결과 영역에 붙여넣습니다. 설명은 제출하지 않습니다.
3. **03 시각화와 해석**: 차트 캡처 이미지를 붙여넣거나 첨부하고 차트 선택 이유·특징·수치 근거를 설명합니다.
4. **04 피봇 테이블**: 만든 피봇 테이블을 제목 행과 함께 붙여넣고 집계 방식·추출한 정보를 설명합니다.
5. **05 데이터 관계 해석**: 데이터 관계를 분석한 차트를 제출하고 관계·근거·해석의 한계를 설명합니다.

표 붙여넣기 영역은 클릭 후 Ctrl+V로 사용합니다. 다시 붙여넣으면 전체 표가 교체됩니다. 미리보기는 100행까지 표시하지만 전체 데이터가 저장·제출됩니다. 웹앱에서는 행 제거나 정답 자동채점을 수행하지 않습니다. 작성 완료 표시는 필수 항목의 존재 및 기본 표 형식만 확인합니다.

## 제출과 평가

학생은 검토 화면에서 학생 정보를 작성하고 제출 JSON 파일을 생성합니다. 이 파일에는 입력한 표, 설명, 이미지가 모두 포함됩니다. 선생님이 안내한 제출 장소에 파일을 업로드해야 실제 전달됩니다.

교사는 교사 평가실에서 제출 파일을 불러와 수행별 0~6점(0.24점 단위, 총 30점)과 피드백을 입력합니다. 전체 답안 평가 화면에서 평가 결과 파일을 내보내 학생에게 전달할 수 있습니다. 학생은 결과 파일을 불러와 점수와 피드백을 확인합니다.

답안은 IndexedDB로 현재 브라우저에 자동 저장됩니다. 다른 기기에서는 JSON 파일로 전달합니다. 이미지 첨부는 PNG/JPG/WEBP, 한 장당 2MB 이하입니다. 답안 수정 시 기존 제출 상태·점수·피드백은 초기화되고 다시 제출해야 합니다. 파일 불러오기는 현재 포트폴리오를 교체하므로 다른 학생을 평가하기 전에 현재 평가 결과를 내보내세요.

현재 구현은 로컬 포트폴리오 방식입니다. 학급별 온라인 수집, 사용자 로그인, 교사 인증, 서버 저장, Google Sheets API 연동은 포함하지 않습니다. 교사 화면 전환은 인증 기능이 아니므로 실제 성적 관리는 교사가 보관한 평가 결과 파일을 기준으로 해야 합니다.

기존 버전 3의 브라우저 저장과 JSON 답안은 새 수행 순서로 이동합니다. 신설된 결측 데이터 수행을 작성하고 다시 제출해야 하므로 기존 제출 상태·점수·피드백은 초기화됩니다. 기존 버전 3 브라우저 저장은 별도 키에 유지됩니다.

## Supabase 온라인 제출

Vercel Production 환경변수에 `SUPABASE_URL`과 `SUPABASE_SECRET_KEY`를 등록합니다. Secret key는 서버에서만 사용하며 GitHub에 저장하지 않습니다. `public.submissions`의 열은 `id uuid`, `student_name text`, `classroom text`, `answers jsonb`, `submitted_at timestamptz`입니다. `classroom`에는 4자리 학번을 저장합니다. RLS를 활성화하고 anon/authenticated 권한은 부여하지 않습니다. Data API 자동 권한 부여를 끈 프로젝트에서는 서버 역할의 INSERT 권한이 필요합니다: `grant insert on table public.submissions to service_role;`.

제출하기는 `/api/submissions`를 통해 답안 전체를 저장합니다. 이미지 원본 data URL과 이미지 이름, 설명, 표 원문 및 이상 데이터 행을 answers에 보관합니다. 전체 JSON 요청은 4MiB 이하, 이미지 한 장은 2MiB 이하입니다. 용량 초과와 저장 실패 시 작성 내용을 유지합니다. 파일 내보내기는 백업용으로 계속 사용할 수 있습니다. 다시 제출하면 새 행이 생성됩니다. 서버 제출 목록 조회와 교사 인증은 별도 구현이 필요합니다. 학생 로그인 없이 제출하므로 학번의 실제 소유자는 인증하지 않습니다.
